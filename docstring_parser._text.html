def split_description(ret: Docstring, text: str): (source) ¶

Set the short and long description from the text before any field.

The short description is the first paragraph: every line up to the first blank or indented one, which an indented block would start. The long description is everything after it. Its lines keep their indent in the dedented docstring, the first one too, which stripping it would lose.

def split_examples(text: str) -> list[Example]: (source) ¶

Split an examples section into examples, the way doctest reads it.

A snippet is a >>> line, the ... lines that continue it, and its expected output: the lines up to a blank line or the next >>> line. The text before a snippet introduces it, and text after the last snippet is an example of its own, with no snippet.

def type_spec(type_name: str | None) -> TypeSpec: (source) ¶

Split the marks of an optional param, and its default, off its type.

The type is split on the commas outside brackets and quotes:

  • A part optional, in any case or emphasized as *optional*, a part ending in (optional) and a part ending in ? mark the param optional.
  • A part default 1, default=1, default: 1, default is 1, defaults to 1 or defaults 1 gives the default, without backticks around it, and makes the param optional too.
  • The other parts are the type.

The same rule holds in every style.
