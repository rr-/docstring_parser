def _after_blank(text: str, match: T.Match[str]) -> bool: (source) ¶

Tell whether a title starts the text or follows a blank line.

A title written in another case than declared starts a section only there, so that prose such as For and example: on the next line stays prose.

def _bare_param(section: Section, text: str) -> DocstringMeta | None: (source) ¶

Build a param from an item whose head has no colon, as in x or x (int), with its description, if any, indented below it.

def _has_item_head(item: str) -> bool: (source) ¶

Tell whether a raises item starts with a head.

That is a type alone on its first line, or something before a colon on it that is no sentence: a type, one word with no spaces, as in ~pkg.Error:, or nothing at all.

def _has_param_head(item: str) -> bool: (source) ¶

Tell whether a param item starts with a head: names, with a type in parentheses or not, before a colon or alone on the line.

A line that has none, such as wrapped prose, goes on with the item before it.

def _head_colon(text: str) -> int: (source) ¶

Find the colon that ends an item's head, or -1 if there is none.

A colon inside brackets is part of the type, as in x (int, default: 3): text, and brackets left open at the end of a line go on to the next, as in a wrapped type. Brackets that never close leave the first colon anywhere.

def _is_union_head(text: str) -> bool: (source) ¶

Tell whether an item starts with a union type and a colon.

The members are split at each | outside brackets, as in dict[str, int | None] | None:, in one pass over the head.

def _join_wrapped(text: str) -> str: (source) ¶

Join the lines of a wrapped item head into one line.

Lines are joined with a space, as wrapped prose and types are written, except right inside brackets: List[ and int] give List[int].
