def _fits_inline(type_name: str | None) -> bool: (source) ¶

Tell whether a type can go inside a field name, as in :param int a:.

A type with a space or a colon in it would read back as more arguments or end the field name early, so it needs a :type: field of its own.

def _join_type(words: list[str]) -> str | None: (source) ¶

Join the words of a field's head that make up one type.

A type can have spaces inside brackets, as in Dict[str, int], after a comma, as in A, B, and around or, of and |. Other words in a row are no type, so the field cannot be read.

Returns
str | Nonethe type, or None if the words are not one
