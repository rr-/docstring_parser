docstring_parser._directives

module documentation
(source)

reST directives in the free text of a docstring, which styles share.

A directive starts at the start of a line, as in:

.. deprecated:: 1.0
   Use `other` instead.

Its body is the indented lines after it. Readers cut the directives they know out of the lines before reading the rest, and keep where each was.

Make a directive starting the docstring start a line.

On the first line, it is dedented with its body. After blank lines, it is read whatever its indent, as the short description it would otherwise give is.

def leading_deprecation(docstring: Docstring) -> DocstringDeprecated | None: (source) ¶

Return the deprecation to write right after the short description.

A deprecation that comes first goes there, as Numpydoc writes it, with the long description read from after it. Not when the long description is followed by a blank line, which it is only when written before the directive, or when it starts indented, which would read back as the directive's body.
